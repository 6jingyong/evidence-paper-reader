# 2026-09-26 round 04

This round promotes a second set of ten tiered benchmark sources into full source-backed audit records.

Unlike round 03, selection is organized as within-domain contrasts against existing source-backed cases: experimental battery work, climate hindcast attribution, a long field warming experiment, a large pragmatic cluster RCT, modern adaptive-UI HCI, a low-attention sensor preprint, deep LOB forecasting, a small medical-education RCT, an externally dependent catalyst critique, and flagship BERT.

Stable public source access was prioritized over forcing a prestige gradient when detailed evidence could not be inspected reliably.
