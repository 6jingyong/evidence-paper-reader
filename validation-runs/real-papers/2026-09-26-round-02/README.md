# 2026-09-26 real-paper round 02 — dirty evidence chains

This round intentionally selects papers that can fool a shallow reader while stressing different failure modes.

- **Gautret HCQ 2020** — open-label non-randomized comparison, PCR surrogate endpoint, treatment-arm exclusions, tiny azithromycin subgroup.
- **Power Posing 2010** — 42 participants, several physiological/behavioral endpoints, borderline statistics, and strong real-world extrapolation.
- **Chocolate weight-loss 2015** — tiny groups, many measured outcomes, selective favorable reporting, promotional conclusion, and later disclosure as an intentional science-journalism hoax.
- **Surgisphere HCQ 2020** — polished large registry analysis whose underlying data provenance could not be independently audited; retracted.
- **Wakefield MMR 1998** — small referred case series with retrospective temporal attribution, later retracted amid documented integrity concerns.

The round deliberately separates two questions:

1. Can a weak or biased paper still be audited? If yes, retain narrow inspectable claims and downgrade overreach.
2. Has the underlying evidence substrate itself become non-auditable? If yes, stop claim extraction and record the source-integrity failure instead of pretending that visible tables remain trustworthy evidence.

Retraction status alone is not the rule. The machine-readable records state why the evidence chain is or is not viable.
